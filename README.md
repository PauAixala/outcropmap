# OutCrop

Browser tools for players of [TerraFirmaCraft](https://github.com/TerraFirmaCraft/TerraFirmaCraft)
and the [TerraFirmaGreg](https://github.com/TerraFirmaGreg-Team/Modpack-Modern) modpack:

- **Map** (`index.html`) — a seed map viewer in the style of chunkbase. Type a world seed, pick a
  profile and a dimension, and pan an endless map of biomes, surface rock, temperature, rainfall,
  terrain and ore veins, with the exact generator values under the cursor.
- **Forge** (`forge.html`) — an anvil calculator. Pick a recipe (or define your own), enter the
  target shown on your anvil, and get an action sequence that lands on it while satisfying the
  recipe's last-three-steps rules.

Everything runs in your browser. There is no server and no account, and nothing is read from your
game or your saves: the map is computed from the seed alone. Use it at
<https://outcropmap.com/>.

How closely it matches the game is checked, not assumed: the tests in `tests/parity/` hold the
generators to values captured from the mod's own Java and, for TerraFirmaGreg, from a real save.
Where a value is only approximate, such as surface height, the app says so.

## Where the data comes from

Nothing here is a copy of the game or of a mod. There are two kinds of content:

1. **World generation and the anvil** (`src/worldgen/`, `src/forge/`) are TypeScript
   reimplementations of the games' own Java algorithms: TerraFirmaCraft's region pipeline, climate,
   biomes, rock layers, rivers, surface height and ore veins, TerraFirmaGreg-Core's own generator on
   top of it, and the anvil's actions and target work. Each port names the Java class and method it
   came from, and ported code is checked against golden fixtures captured from the real Java
   (`tests/parity/`, `tools/parity/`).
2. **Extracted tables** (`src/data/tfc-1.20/`, `src/data/tfg/`) are values regenerated by the scripts
   in `tools/` from TerraFirmaCraft's source and datapack, from the TerraFirmaGreg modpack
   repository, and from an installed copy of the modpack: vein definitions, rock and biome lists,
   structure sets, dimension climate, anvil recipes and action deltas. Each file's `_meta` block
   records where it was read from. The forge's TerraFirmaGreg catalogue is the game's own anvil
   recipes, keeping only those from mods whose licence allows publishing them.

[`NOTICE.md`](NOTICE.md) lists every source, its licence and exactly what is taken from it.

Icons, glyphs and textures are original artwork made for this project. No textures, models, sounds
or other game or mod assets are included.

## Privacy

OutCrop keeps your seed, settings, waypoints and custom recipes in your own browser
(`localStorage`) and never sends them anywhere. There are no analytics and no accounts.

The public site carries ads from Google AdSense, which uses cookies. Visitors in the European
Economic Area, the United Kingdom and Switzerland are asked for consent first, and "Privacy and
cookie settings" at the top of every page changes that choice. The site's Privacy page has the
details.
